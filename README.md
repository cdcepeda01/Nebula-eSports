# 💬 Nebula eSports Chat
Aplicación web de chat enfocada en la comunidad **eSports**, inspirada en **Discord** y **Twitch**.  
Proyecto desarrollado para la clase de **Taller de Diseño Multimedia** de la carrera Ingeniería Multimedia de la Universidad de Boyacá.
